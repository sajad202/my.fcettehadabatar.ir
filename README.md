# پکیج رسمی ساخت خودکار APK اندروید در گیت‌هاب — باشگاه فوتسال اتحاد اباتر

این بسته با تنظیمات اختصاصی پنل مدیریت شما تولید شده است.

## مراحل دریافت فایل APK از گیت‌هاب (بدون نیاز به برنامه‌نویسی):
1. یک Repository جدید در GitHub بسازید.
2. محتویات این فایل ZIP را در آن آپلود (Commit / Push) کنید.
3. وارد تب **Actions** در گیت‌هاب شوید و روی **Build Android APK (TWA)** کلیک کنید.
4. پس از اتمام تیک سبز، از قسمت **Artifacts** فایل نصبی **APK** آماده را دانلود کنید!
5. سپس می‌توانید فایل APK دانلودشده را در پنل ادمین ← «اپلیکیشن اندروید (APK)» آپلود کنید تا بازیکنان مستقیم از سایت دانلود کنند.
